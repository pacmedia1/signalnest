# n8n workflows

Four importable workflows. **Do not hand-edit these files**: they are generated by `node scripts/build-workflows.js`, which also validates every graph. Edit the generator instead.

| File | Trigger | Writes to |
| --- | --- | --- |
| `signalnest-01-discovery.json` | Schedule, 6h | `content/queue/topics.json` |
| `signalnest-02-generation.json` | Schedule daily + manual | `content/drafts/<slug>.json` |
| `signalnest-03-publishing.json` | 3 authenticated webhooks | `content/articles/<slug>.json` |
| `signalnest-04-analytics.json` | Schedule weekly + manual | `content/analytics/weekly-<date>.json` |

Requires n8n 1.40 or newer. Set the host environment variables from `docs/SETUP.md` before running anything, and confirm `$env` access works (see the same document).

Full import steps, node-by-node behaviour and a safe test order: `docs/WORKFLOWS.md`.

Regenerate after any change:

```bash
node scripts/build-workflows.js
```
